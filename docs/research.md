# 调研与头脑风暴（2026-09）

项目：中国风六爻起卦网站，用 TypeSafe Jev 做语义判断。源码公开，禁止商用。本文汇总立项时 5 路调研的结论，给后续写 `AGENTS.md` 和开发用。标为「待定」的条目需要项目负责人拍板。

## 0. 结论速览

| 维度 | 结论 |

## 1. 合规（决定定位和部署）

> **已定（2026-09-26）：只面向海外华人。** 下面的大陆法规结论仍然保留，作为背景；大陆备案、微信域名这些限制不再影响部署。安全相关的红线继续执行。

- 2026-04 网信办「清朗·整治 AI 应用乱象」把「AI 算命」列为违规功能服务；2026 春节专项点名「网上算命占卜」。《互联网信息服务管理办法》第 15 条禁止宣扬封建迷信。
- 在大陆备案这条路走不通：要实名备案，类目被点名，调用境外未备案模型也无法登记。
- 微信：小程序禁止算命、抽签类内容；外链违规会被封域名；未备案域名在微信里会弹「非微信官方网页」提示。
- **红线（MVP 起执行）**
  - 界面不出现「AI 算命」「改命转运」「化解」等字样
  - 不收费，不卖转运物，不收集姓名、生辰、手机号、住址
  - 不写恐吓式断语；不给医疗、法律、投资结论；不预测彩票、赌博
  - 结果页常驻：「AI 辅助判断 · 仅供传统文化参考与娱乐，不构成医疗、法律、投资建议」
  - 识别到自伤倾向时停止解卦，显示心理援助热线 12356
  - 同一件事不重复起卦（「初筮告，再三渎」）：既符合传统，也防止用户形成依赖

来源：[网信办 2026-04](https://www.cac.gov.cn/2026-04/30/c_1779289298718765.htm) · [清朗 2026 春节](https://www.news.cn/legal/20260212/c7ad9636adb44ce7a89f41d6f4a15376/c.html) · [微信外链规范](https://weixin.qq.com/agreement/weixin_external_links_content_management_specification) · [12356](https://www.news.cn/politics/20250508/b45e439c15bb4732858ad5c7640e9ba9/c.html)

| 竞品 | 长处 | 短处 |

- 专业用户要看：干支四柱（按节气定月）、月建日辰、旬空、纳甲、六亲、六神、世应、动变、伏神、用神与旺衰依据。

## 3. 六爻引擎

### 3.1 流程
起卦 → 本卦、变卦、动爻 → 装卦（纳甲、卦宫五行、六亲、世应、六神）→ 月建日辰、旬空 → 用神 → 旺衰（月日生扶克冲、月破、旬空）→ 动爻的回头生克、进退神 → 伏神 → 吉凶。

- **铜钱：** 背面记 3，字面记 2。一背为少阳，二背为少阴，三背为老阳（动 ○），三字为老阴（动 ×）。依据《卜筮正宗》。随机数用 `crypto.getRandomValues`。
- **查表部分：** 64 卦、纳甲、卦宫、六神起点、旬空、用神类别。
- **规则部分：** 世应、六亲生克、伏神、旺衰、月破、进退、回头生克。
- **MVP 暂不做：** 三合、三刑、墓绝、神煞、应期。

### 3.2 已知陷阱
- 变卦的六亲按**本卦**的宫来排。
- 游魂卦按世爻定宫。火地晋属乾宫，不是离宫，原版 Python 库在这里有 bug。
- 干支必须按节气的精确时刻算。例如 2025-02-03 22:00 是甲辰年丁丑月，22:20 是乙巳年戊寅月（立春在 22:10:28）。tyme4ts 默认就按精确时刻；lunar-javascript 要用 `*Exact` 系列方法。
- 起卦时刻一律按 **UTC+8** 计算，与用户和服务器的时区无关。
- 晚子时（23–24 点）换不换日有两派，做成选项。

## 4. Jev（TypeSafe System One）

- `POST https://api.typesafe.ai/v1/systemone`，鉴权 `Bearer <key>`，`model: "jev-latest"`。JS SDK 是 `@typesafe-ai/sdk`（Node 20 以上）。
- 三种题型：Choice（单选，返回概率和置信度）、Noul（是 / 否的概率）、Score（分档打分）。**不生成文字。**
- 价格：输入 $0.042 / 百万 token。一次解卦约 3k token，约 $0.00013。
- 中文能处理，但官方说准确率不如英文。第三方实测现代中文分类表现良好，Score 对档位的措辞很敏感。
- 延迟：美西机房约 0.1–0.5s，国内约 0.85–1s，偶尔 20–90s。SDK 的超时按单次尝试算，需要自己设总超时。
- **账号：官方从 2026-09-22 起暂停新注册**，已有账号不受影响。替代接入：Vercel AI Gateway（`typesafe-ai/jev`，价格相同）；SDK 可以通过 `baseURL` 切换。
- **局域网测试服务器已验证可以连通：** 宿主机和 Docker 容器都能访问 api.typesafe.ai（约 0.5s）。

### 4.1 Jev 在产品里的位置
在「写下所问」提交时**只调用一次**。这时用户进入静心环节，大约 12 秒，正好盖住请求延迟。所有问题只依赖问题文本，所以可以并发一起发出。

| id | 题型 | 用途 |
|---|---|---|
| `topic` | Choice | 财 / 官（事业）/ 父母（房屋、文书）/ 子孙（子女、医药）/ 兄弟（竞争、合伙）/ 婚恋 / 自身 / 无法判断。由代码映射到用神 |
| `self_harm` | Noul | 自伤倾向：阻断起卦，显示 12356 |
| `emergency` | Noul | 需要就医、报警、找律师的紧急情况：温和劝导 |
| `gambling` | Noul | 求彩票号码或赌博结果：婉拒 |
| `sincere` | Noul | 是否是真诚、具体、能回答的问题 |

- 安全判断一律用 Noul，阈值在代码里设。不要在 Choice 里放「有害」选项。
- `topic` 置信度低（约 0.6 以下）、请求超时、或者没有 key 时，都让用户自己点选类别。**所以没有 Jev 也能完整走完流程。**
- 婚恋类的用神与性别有关（男问取妻财，女问取官鬼）。只在这一类下，用两个按钮问性别，不做表单。
- **吉凶由代码规则判定**（用神旺衰、动变），Jev 不参与。
- 以后可以加：用 Score 判断哪条爻辞和处境最相关、判断用户的焦虑程度来选模板语气、问题类型（成败 / 应期 / 取舍）。

## 5. 技术栈与部署

> **已定：** 因为只面向海外，生产改用 Cloudflare Workers + `@astrojs/cloudflare`。`astro preview` 本身就跑在 workerd 上，局域网测试服务器用 Docker 跑出来的环境与线上一致；限流用 Workers `ratelimit` binding（已 GA）。下面是最初按「面向大陆」得出的方案，留作记录。

- **Astro + `@astrojs/node`（standalone）：** 页面全部预渲染，只有 `src/pages/api/judge.ts` 在服务端运行。Jev 的 key 只放服务端环境变量，变量名不带 `PUBLIC_` 前缀。
- **样式：** scoped CSS + CSS 变量，不引入 Tailwind。
- **动画：** CSS 3D 做铜钱翻转，WAAPI / CSS 做过渡，扫描的毛笔笔触图配合 mask 揭开来画爻，SVG `feTurbulence` 做墨边。GSAP 现在免费了，编排复杂时再加。不用 three.js，不用 Lottie。
- **运行时：** Node 22 或 24 LTS + pnpm。
- **部署：** 多阶段 Dockerfile + compose（app + Caddy）。测试和生产用同一份 compose。
- **生产环境对比：**
  - 香港 VPS（腾讯云国际站 Lighthouse 约 $6/月）：大陆延迟 30–50ms。**推荐。**
  - Vercel、Cloudflare：在大陆被污染或延迟高。
  - 大陆云：需要备案，见第 1 节，走不通。
- **`/api/judge` 必须限流：** 这是公开接口，背后是付费 key。
- 分享卡默认不含「所问」，卡上所有字都在字体子集里，所以在客户端用 canvas 生成就够了，MVP 不需要服务端渲染。

## 6. 视觉与交互

### 6.1 风格：C 夜色烫金 + A 宋式宣纸
色值都取自 zhongguose.com。

| 用途 | 色名 | 色值 |
|---|---|---|
| 暗场底 | 燕颔蓝 | `#131824` |
| 暗场分层 | 鸽蓝 | `#1c2938` |
| 金 | 桂皮淡棕 | `#c09351` |
| 金色高光 | 浅驼色 | `#e2c17c` |
| 印章红 | 鹅血石红 | `#ab372f` |
| 纸底 | 汉白玉 | `#f8f4ed` |
| 纸上文字 | 牛角灰 | `#2d2e36` |
| 次要文字 | 瓦灰 | `#867e76`（设计稿里加深为 `#6e665e`，保证对比度） |
| 线 | 珍珠灰 | `#e4dfd7` |
| 纸上的朱印 | 朱红 | `#ed5126`（面积不超过 2%） |

- **为什么这样搭：** 人通常在夜里、拿着手机、心里有事的时候算卦。暗场里金线一笔一笔写出爻来，像走进一个空间；出结果时切换到纸色，形成从「问」到「答」的转场。
- **要避开：** 大红大金、龙纹、祥云素材、满屏八卦图、紫色星空（会变成廉价塔罗）、金色倒角高光（会像手游充值页）。
- **字体（全部自托管，按 unicode-range 切片）：**
  - 正文：Noto Serif SC（OFL，可以子集化）
  - 标题：原计划用霞鹜文楷，但它在 Google Fonts 上只有繁体版。**已改用站酷小薇**（ZCOOL XiaoWei，OFL，`@fontsource/zcool-xiaowei`）。
  - 不要依赖 Google Fonts 或 jsDelivr：在大陆不稳定。

### 6.2 起卦流程（移动端优先）
| 步骤 | 用户做什么 | 时长 |
|---|---|---|
| 首屏 | 全屏暗场，一条金线呼吸，一句「心有所疑，不妨一问」，一个「起卦」按钮。不放导航，不放八卦图 | — |
| 写下所问 | 输入一件事，提示「一事一问」。提交后文字收成一枚印，**同时调用 Jev** | 用户决定 |
| 静心 | 跟着金环呼吸 3 次，可以跳过 | 约 12 秒 |
| 摇卦 ×6 | 长按摇动，松手掷出。铜钱翻 1.2 秒后落定（Android 会震动），爻从下往上写出 | 每爻约 4 秒 |
| 成卦 | 静默 1.5 秒，卦名以墨晕浮现，动爻微亮，变卦在旁边生成 | 约 5 秒 |
| 解读 | 切到纸色页面：结论 → 卦辞、动爻爻辞 → 建议 → 折叠的完整盘面 | 自行滚动 |

- 一屏只做一件事。不放进度条，已经写出的爻就是进度。摇卦过程中不能重摇，也不能后退。所问一直以小字悬在顶部。
- `prefers-reduced-motion` 开启时：铜钱直接显示结果，爻淡入，但停顿保留。仪式感来自节奏。
- 音效：一段铜钱落盘声，一段成卦时的磬声，用 Web Audio 现场合成（M9 定，原计划用 CC0 素材）。**默认关闭。**
- 分享卡：3:4，1242×1656。卡上放六爻、卦名、一句卦辞、干支日期和印章。所问默认不上卡。用 `<img>` 展示，让用户长按保存（微信里没有 `navigator.share`）。
