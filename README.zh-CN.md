# 六爻 · liuyao

英文 `/en/` 提供同一套铜钱与手动起卦、解读、往卦、回访、提醒和分享卡；`/en/gua/` 与 64 卦页配本项目原创英文释义，经文保留中文并明示未翻译。三语共用规则与本机记录，其他工具仍只提供简繁界面。

**[sixyao.app](https://sixyao.app)** · [English](README.md)

中国风六爻起卦网站。写下所问，静心，摇六次铜钱，成卦，读解。六爻起卦、手动排盘与六十四卦页均有简繁两版；繁体以台湾用语为准，入口在 `/zh-hant/`。另有黄历栏目 `/huangli/`：每天的宜忌、冲煞、建除、值神，由 tyme4ts 推算，加二十四节气的交节时刻、三候与时令，简繁都有。黄历栏目里还有择日 `/zeri/`：按搬家、结婚、开业、出行、装修、订婚六件事，列出每个月宜忌合用的日子，可按生肖避冲（选的生肖只记在本机浏览器里）。另有八字排盘 `/bazi/`：输入生辰（可选出生城市，海外按当地时区、含历史夏令时），在浏览器里排出四柱、十神、藏干、纳音、神煞、刑冲合会、大运与流年，盘面之后用白话把日主、五行与十神、大运说一遍，只讲有什么、叫什么，不下断语；生辰不上传，要存只存在本机，简繁都有。另有梅花易数 `/meihua/`：写下所问，以此刻的年月日时（北京时间）或报一两个数起卦，按体用生克断；所问的安全分流、一事一占与往卦都和六爻共用（简繁都有）。

另有取名栏目 `/quming/`：测名只在浏览器里算康熙笔画、读音、三才五格与英文写法；起名从 34 组《诗经》《楚辞》摘句浏览候选，列出本盘五行个数与原创字五行意象，完整姓名通过中英文谐音及禁词表检查。姓名、生辰不上传、不存、不进网址，结果用设备字体。八十一数 `/quming/81/` 只写数的构成与意象，不分吉凶；单字目录 `/zi/` 收录 2,015 个名字与姓氏用字的原创字义、读音、笔画与公开用字统计。简繁都有。

- **排盘由程序完成**：纳甲、六亲、世应、六神、旬空、伏神、旺衰都是确定性计算，同一卦永远排出同一盘，并用《增删卜易》卦例和 4096 组全量对照做测试。
- **吉凶由规则判定**，并列出依据，不交给模型。
- **语义判断用 [TypeSafe Jev](https://docs.typesafe.ai)**：给问题分类以确定用神，并识别自伤、急事、赌博等不宜占问的情况。Jev 不可用时由用户自选类别，流程照样走得通。
- **解读**：卦爻辞原文，加本项目原创的白话。
- **手机上**可以长按「摇」，也可以开启摇一摇，直接摇手机。
- **免费、无广告、不登录。** 访问量只用 Cloudflare Web Analytics 统计：不用 cookie，不追踪个人，不接其他统计。往卦和事后记下的「后来怎样」只存在本机浏览器；到时提醒加进你自己的日历，只带日期和卦名：日历文件在本机生成（iPhone、iPad 上由服务端按网址现生成，不存不记），Google 日历用预填好的新建日程；不收邮箱，不推送。所问只发给 Jev 分类一次，本站不记录。

风水栏目 `/fengshui/` 提供本地命卦、宅卦、手动方位盘，本地图旋转对北并叠九宫，以及沈氏正向下卦飞星。每山只排中间九度，兼向与临界读数明确拒绝；另有年度九宫页、81 条原创中性空间札记，简繁都有。生年、住房读数和图片不上传、不存，离页清空。手机自动罗盘待真机校准后开放。

## 技术栈

Astro 7 · Cloudflare Workers · TypeScript · [tyme4ts](https://github.com/6tail/tyme4ts)（历法） · Vitest。页面全部预渲染，服务端路由只有两个：调用 Jev 的 `/api/judge`，和给 iPhone、iPad 现生成提醒日历文件的 `/api/remind.ics`。
